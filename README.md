# TRAC Scraper and Louisiana Map Pipeline
Scrapes the Transactional Records Access Clearinghouse's map of Louisiana's pending immigration cases by immigrant's address and pipes the CSV into two Datawrapper maps and a table via a daily cron job using GitHub Actions.
